# MNIST SPMI 短轮次 Shadow 实验分析

## 1. 结论

这组预实验支持继续研究 `SPMI_abs`，但同时否定了“只比较当轮 RBLA 与
RBLA+ 的即时测试 loss，就能判断长期应该使用哪个方法”的想法。

在本次六个 MNIST 条件中：

- 前 5 轮平均 `SPMI_abs` 与现有 100 轮 RBLA+ 相对 loss 收益的 Pearson
  相关系数为 **0.797**；
- 最终由 RBLA 胜出的两个条件，平均 `SPMI_abs` 为 **0.0917–0.0934**；
- 最终由 RBLA+ 胜出的四个条件，平均 `SPMI_abs` 为 **0.1117–0.1251**；
- 使用 `SPMI_abs >= 0.10` 选择 RBLA+，否则选择 RBLA，在这六个条件上
  得到 **6/6 正确**；
- 不只条件均值可分：30 个逐轮观测也全部位于阈值正确一侧。RBLA 条件的
  最大逐轮值为 **0.097825**，RBLA+ 条件的最小逐轮值为 **0.103969**。

这是单数据集、单 seed 的探索性结果，不能把 0.10 当成已证明可迁移的通用
常数。但它说明这个无数据量有可能在训练早期识别“规范化是否值得持续做”。

## 2. 实验设置

- 数据集：MNIST；
- seed：42；
- 客户端数量：10；
- 联邦训练：每个条件 5 轮，每轮客户端本地训练 5 epoch；
- 数据分布：Dirichlet `alpha ∈ {0.4, 0.8}`；
- rank 与客户端数据量相关性：`rho ∈ {-0.5, 0, +0.5}`；
- 共 6 个条件、30 个 round-level 观测；
- 正式训练和广播始终使用现有 RBLA；
- 每轮 RBLA 聚合后，只在只读 shadow 分支构造规范化后的 RBLA+ 候选；
- SPMI 只读取 LoRA 因子、客户端 rank 和聚合权重，不读取样本；
- 固定、类别均衡的 2,000 个 MNIST test 样本只用于离线验证 shadow
  RBLA/RBLA+ loss，不参与 SPMI；
- 长期赢家来自仓库中相同配置已有的 100 轮 RBLA/SP+ 配对结果。

实验没有修改现有 RBLA、SP+、canonicalization、客户端策略或 runner。

## 3. 指标

对层 `l` 的聚合 LoRA 更新 `Delta W_l = B_l A_l`，客户端可接收 rank 为
`r_il`。原始 RBLA 前缀的残差为：

```text
R_raw,l(r) = ||B_l A_l - B_l[:,:r] A_l[:r,:]||_F^2
           = ||B_l[:,r:] A_l[r:,:]||_F^2
```

SVD 规范前缀的最优 rank-r 残差为：

```text
R_opt,l(r) = sum_{j>r} sigma_l,j^2
```

客户端的 prefix mismatch opportunity 是两者之差。实验使用客户端数据量权重
`w_i` 汇总，并用完整 LoRA 更新能量归一化：

```text
SPMI_abs =
    sum_i w_i sum_l [R_raw,l(r_il) - R_opt,l(r_il)]
    -------------------------------------------------
                  sum_l ||B_l A_l||_F^2
```

所有 Frobenius 能量均通过 rank-sized Gram matrix 计算，没有显式构造稠密
`B_l A_l`。

在间接复述 Dirichlet alpha。

## 5. 阈值稳定性

按每个条件前 5 轮的平均值分类：

| SPMI_abs 阈值 | 正确条件数 |
|---:|---:|
| 0.090 | 4/6 |
| 0.095 | 6/6 |
| 0.100 | 6/6 |
| 0.105 | 6/6 |
| 0.110 | 6/6 |
| 0.115 | 3/6 |
| 0.120 | 3/6 |

0.10 不是唯一能工作的点。条件均值上的完全分离区间约为
`(0.093445, 0.111656]`；要求每一个单轮观测都正确时，分离区间缩小为
`(0.097825, 0.103969]`。0.10 位于两者内部。

使用 0.10 时，只看第 1 轮、前 2 轮均值、前 3 轮均值或前 5 轮均值，在这次
实验中都是 6/6。不过论文方法仍建议至少观察 3 轮并使用 EMA，不能根据单 seed
结果宣称一轮检测已足够可靠。

## 6. 为什么原来的 0.01 阈值不合适

六组的 `SPMI_rel` 都在 **0.993–0.998**，几乎饱和；`SPMI_abs` 也全部远高于
0.01。因此原先：

```text
SPMI_abs >= 0.01 and SPMI_rel >= 0.10
```

会对六组全部选择 RBLA+，只能得到 4/6 的长期方法选择准确率。

同时，当轮 shadow RBLA+ 的相对 loss 改善只有 **0.005%–0.009%**，而且六组
全部为正。它与最终长期收益的符号并不一致：例如 `alpha=0.8, rho=0` 当轮
RBLA+ 略好，但 100 轮后 RBLA 的 loss 明显更低。

这揭示了两个不同问题：

1. `R_raw - R_opt` 是否大于零：SVD 前缀在参数空间中是否更优；
2. 这种优势是否大到足以抵消持续 canonicalization 对优化轨迹和因子坐标系
   连续性的影响。

0.01 更接近问题 1 的“存在性阈值”；0.10 才是本次实验支持的问题 2 的
“方法选择阈值”。

## 7. 建议的初版门控

论文初版可以采用：

```text
前 3 轮：
    只使用 RBLA
    每轮计算 SPMI_abs

round 3 后：
    score = mean(SPMI_abs_1, SPMI_abs_2, SPMI_abs_3)

    if score >= 0.10:
        后续统一使用 RBLA+
    else:
        后续统一使用 RBLA
```

如果需要动态切换，可使用慢速 EMA 和滞回：

```text
EMA >= 0.105，连续 2 次：RBLA -> RBLA+
EMA <= 0.095，连续 2 次：RBLA+ -> RBLA
最短驻留时间：10 轮
```

对于当前论文问题，更建议先研究“一次早期选择”，因为它复杂度低、变量少，
也更容易解释。动态切换可以作为扩展实验。

## 8. 不能过度解读的部分

- 只有 MNIST；
- 只有 seed 42；
- 只有六个分布/rank 配置；
- 0.10 是看过这六组长期结果后得到的 pilot 阈值，存在选择偏差；
- 即时 shadow 评估使用测试子集，只能作为离线 oracle，不能用于正式训练；
- Pearson 0.797 的样本量只有 6，不应报告显著性结论；
- 下一步至少需要多个 seed，并把阈值固定后在未参与选阈值的数据集或配置上测试。

因此当前最稳妥的表述是：

> SPMI_abs 在 MNIST 六条件 pilot 中表现出早期区分 RBLA 与 RBLA+ 长期赢家的
> 能力，支持将“何时值得进行全局 LoRA 因子规范化”作为一个独立研究问题；
> 其跨 seed、跨数据集可迁移性仍待验证。
